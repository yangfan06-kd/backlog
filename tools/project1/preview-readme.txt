项目进展（内测版）使用说明

1. 双击本目录中的“启动项目进展内测版.cmd”。
2. 不需要安装 Node、启动网页服务器或命令行窗口。
3. 数据默认保存在 G:/project1/output/runtime/project1-preview/，重建包不会覆盖该目录。
4. 左侧有四个业务入口，底部是“数据备份”和“关于”。
5. “数据备份”会自动保留本机完整版本，也可手动导出或从备份文件恢复；恢复会替换本机数据。
6. 自动版本只保存在本机，不等于云备份；损坏版本不能恢复。
7. 这是 Windows x64 解包目录内的内测包，不是正式安装版，也没有安装器、卸载器、云备份或自动更新。
8. 本包基于开源 Super Productivity（Angular + Electron）二次开发，保留上游许可证和致谢。

如果直接双击 win-unpacked 内的 exe 而没有启动入口，程序会安全退出，不写入默认 AppData 数据目录。
