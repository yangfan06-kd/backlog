# 项目进展（Project Progress）

一个面向 Windows 的本机优先个人项目管理工具，用来整理项目、推进步骤、记录每天实际发生的事，并用四象限总览查看全局。

当前公开试用版：**0.1.0-beta.60（Windows x64）**。

> 这是试用版，安装包未签名。升级或重装前，请先导出完整备份并关闭应用。

## 下载与安装

- 安装包请从 [GitHub Releases](https://github.com/yangfan06-kd/backlog/releases) 下载。
- 解压发布压缩包，运行 `ProjectProgress-Setup-<版本>-x64.exe`。
- 默认程序目录：`%LOCALAPPDATA%\Programs\ProjectProgress`
- 用户数据保存在程序目录相邻的 `ProjectProgress-data` 目录中。
- 卸载程序只移除程序，不会删除相邻的数据目录。
- 升级时保持原安装位置覆盖安装即可；重要数据请先导出完整备份。

## 主要功能

- **四象限总览**：按紧急、重要程度整理项目，快速看到各象限中的项目和剩余步骤。
- **项目进展**：项目下按顺序维护步骤，完成后生成当天的实际完成记录。
- **按项目显示日期**：只显示当前可见项目实际有记录的历史日期；只有今天记录时不显示历史列和展开按钮，项目、今天和剩余步骤三列均分宽度。
- **搜索页**：独立搜索入口，可按项目、常态事项、步骤、记录和备忘查找；支持日期、文件夹、状态筛选和最近搜索。
- **快记**：从侧栏快速记录项目进展、常态事项或备忘，不需要先进入对应页面。
- **复盘**：按本周或本月查看完成、有推进和需要回看的项目与记录；可切换到上一周/上一月并复制复盘摘要。
- **项目文件夹**：创建、重命名、删除和拖动排序文件夹；项目可拖入文件夹，文件夹内可继续排序和新建项目。
- **未来计划日期**：计划日期和实际完成记录分开，未来项目不会提前算作已完成。
- **补记与历史记录**：可以补写过去某天的记录，也可以在允许时直接编辑历史记录。
- **步骤撤回**：每条来自步骤完成的历史记录都可以单独退回剩余步骤，并按项目最新顺序校验。
- **常态事项**：维护长期反复发生的事项，按日期表格查看和补记。
- **备忘**：记录独立的备忘事项，可选提醒时间。
- **项目归档与回收站**：完成后归档；删除的项目先进入回收站，也可以永久删除。
- **本机自动备份**：自动保留本机备份版本，支持恢复和批量删除旧备份；文件夹和归属关系一并备份。
- **本机优先**：无需账号，不依赖云服务；数据默认保存在本机。

## 技术栈

- **桌面壳**：Electron 44.7.0，主进程 + 安全 preload + 渲染进程，关闭渲染进程 Node 集成并启用上下文隔离。
- **前端框架**：Angular 22.2.2，standalone components、signals、依赖注入；Angular Material / CDK 22.2.2。
- **状态与数据流**：NgRx Store / Effects 22.0.1；RxJS 7.8.2；操作日志（op-log）记录本地变更。
- **本机存储**：IndexedDB（idb 8.0.3）保存操作日志、归档和缓存；自动备份与完整备份为 JSON 文件。
- **语言与样式**：TypeScript 6.0.3；SCSS 设计变量与自定义样式层；ngx-translate 17 提供中英文文案。
- **构建与安装**：Node.js 22（`.nvmrc` 为 v22.23.3）；npm 11；Electron Builder 26.16.1 生成 NSIS Windows x64 安装包。
- **测试**：Playwright 1.59.1 做浏览器/Electron 流程测试；Jasmine + Karma 做 Angular 单元测试。
- **移动端保留能力**：上游的 Capacitor 8.5.3 相关代码仍保留在仓库中，但当前 Windows 试用版不包含移动端交付。

## 数据与更新

- 当前版本没有云备份、跨设备同步或手机客户端。
- 自动备份和业务数据在同一台电脑上，不能替代异地备份；重要资料请定期导出完整备份。
- 完整备份和本机自动备份都会包含项目文件夹及项目归属关系。
- 软件没有在线自动更新器，更新方式是用更高版本的安装包覆盖安装。

## 从源码构建

需要 Node.js、npm 和 Windows 上的 Electron 依赖。

```powershell
npm ci
npm run buildFrontend:prod:es6
npm run electron:build
node tools/project1/build-public.cjs 0.1.0-beta.60
node tools/project1/prepare-delivery.cjs 0.1.0-beta.60
```

构建产物、安装包和用户数据不会提交到源码仓库。
